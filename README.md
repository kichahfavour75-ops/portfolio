# Professional Portfolio

A responsive, modern developer portfolio built with React, TypeScript, Vite, Framer Motion, and Lucide.

## Requirements

- Node.js 18+ recommended
- npm 9+ recommended

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Customize

Most personal content is in:

`src/data/portfolio.ts`

Edit:
- name
- professional title
- location
- email
- social links
- bio
- about text
- skills
- experience
- projects
- education
- certifications

Add your own:
- `public/profile.jpg`
- `public/resume.pdf`

## Important

Replace the sample project links and remote project images with your own work before publishing.

For a production site, consider adding a real contact form service or backend rather than relying only on `mailto:`.
